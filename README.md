# C Practice

Not learning C from scratch — I have C++ basics. This repo tests whether I can read/write C in the style used by llm.c and other HPC code.

## Focus areas

- Raw pointer arithmetic over multi-dim arrays
- Manual malloc / free
- C-style idioms (no classes, no templates, no STL)

## Exercises

- `exercises/01_matmul.c` — Matrix multiply over raw `float*` buffers
- `exercises/02_meanvar.c` — Compute mean & variance
- `exercises/03_tensor_index.c` — 4D tensor indexing with pointer arithmetic
